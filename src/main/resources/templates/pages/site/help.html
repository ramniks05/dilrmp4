Navigating the website

  • The main menu at the top of every page gives access to Home, Chart, Naksha, Report, Download, Login and Contact pages.
  • The links at the bottom of every page give access to Website Policies, Help, Sitemap, Feedback and Contact Us.
  • The Sitemap lists all the main pages of the website.
  • Use the Skip to main content link (first link on every page, available with the Tab key) to move directly past the menus to the page content.
  • All features can be used with the keyboard: Tab moves to the next link or control, Shift + Tab moves back, and Enter activates it.

Accessibility features

The accessibility bar at the top of every page provides the following options. Your choice is remembered in your browser.

Accessibility options
Option What it does
A- / A / A+ Decrease, reset or increase the text size of the page.
High contrast (dark A) Shows the page in white and yellow text on a black background.
Normal contrast (light A) Returns the page to its standard colours.
Skip to main content Moves the keyboard focus directly to the main content of the page.

Links that open in a new window are announced as such, and a message is shown before you are taken to a non-government website. The scrolling announcement on the home page can be paused with its Pause button, or by moving the mouse or keyboard focus over it.

Screen Reader Access

This website complies with the Guidelines for Indian Government Websites (GIGW 3.0) and the Web Content Accessibility Guidelines (WCAG) 2.1 level AA. This enables people with visual impairments to access the website using assistive technologies, such as screen readers. The following table lists information about different screen readers:

Screen readers

Non Visual Desktop Access (NVDA) https://www.nvaccess.org/ Free

JAWS https://www.freedomscientific.com/products/software/jaws/ Commercial
Supernova https://yourdolphin.com/ Commercial
VoiceOver (macOS / iOS) https://www.apple.com/accessibility/vision/ Free (built in)
TalkBack (Android) https://support.google.com/accessibility/android/ Free (built in)

Viewing information in various file formats

Reports on this website can be downloaded in the following formats. You may need the software listed below to view them.

File formats and viewers
Document Type Software / Plug-in
Portable Document Format (PDF) Adobe Acrobat Reader (https://get.adobe.com/reader/) or any modern web browser
Microsoft Excel (XLS / XLSX) Microsoft Excel, LibreOffice Calc (https://www.libreoffice.org/) or Microsoft Excel Viewer

Reports and downloads

  • Report shows physical progress reports. Select a State/UT to see district-wise details.
  • Download lets you download reports as PDF or Excel files. The file type is shown by the PDF and Excel icons next to each report.
  • Data shown is entered by the respective State Governments/UT Administrations.

Login help

  • Login is available only to authorised officers of the Department of Land Resources, the States/UTs, Districts and IGR offices.
  • If you have forgotten your password, use the Forgot Password option on the login page.
  • For any other problem, please see Contact Us.
